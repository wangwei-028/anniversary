## 一、怎么运行

> 为什么不能直接双击 `index.html`？Chrome / Edge 出于安全策略，禁止 `file://` 页面加载 ES 模块（这是浏览器限制，不是 bug）。所以准备了下面几种零安装的方式：

| 方式 | 操作 | 适合 |
|---|---|---|
| ① 一键启动（推荐） | 双击 **`启动游戏.bat`** → 自动开本地服务器并打开浏览器（关闭黑窗口即停止） | Windows 电脑 |
| ② Firefox | 用 Firefox 直接打开 `index.html`（Firefox 允许本地模块） | 临时看一眼 |
| ③ 任意静态服务器 | 在项目目录执行 `python -m http.server 8000`，打开 `http://localhost:8000` | 有 Python 的电脑 |
| ④ GitHub Pages | 把整个文件夹推到 GitHub 仓库 → Settings → Pages → 选 main 分支根目录 | **手机上玩（最终送礼方式）** |

- `启动游戏.bat` 调用 `tools/serve.ps1`：Windows 自带 PowerShell 写的迷你服务器，只监听本机 `localhost`，只提供项目目录内的文件。
- 直接双击 `index.html` 时，页面会显示中文提示告诉你怎么打开。

### 在手机上测试（同一 Wi-Fi）

1. 电脑上在项目目录执行：`python -m http.server 8000 --bind 0.0.0.0`（Windows 防火墙弹窗选"允许"）
2. 电脑命令行 `ipconfig` 查到局域网 IP（如 `192.168.1.23`）
3. 手机浏览器打开 `http://192.168.1.23:8000`（竖屏）
4. 测完记得 Ctrl+C 关掉服务器

### 调试模式

网址后加 `?debug=1`（如 `http://localhost:8765/?debug=1`）：左下角显示 FPS / 速度 / 距离 / Boss 状态，并启用快捷键：

| 键 | 作用 |
|---|---|
| B | 跑酷段直接跳到 Boss 战 |
| G | 无敌开关（被撞不扣心） |
| K | Boss 战中让 Boss 直接掉 1 血 |
| T | 慢动作开关（0.4 倍速，方便看动画） |
| 0 | 清空存档 |
| M | （选关 / 商店画面）+5000 金币 |
| U | （选关画面）第 1~7 关全部标记为通关（解锁无尽模式、婚纱皮肤） |
| F | （选关 / 标题画面）集齐 21 片照片碎片（解锁回忆放映厅的门、Boss Rush） |
| B | （无尽模式）立刻来一次 Boss 客串；（Boss Rush）当前 Boss 直接击败 |

### 开发者模式

`config.js` 里把 `devMode` 改成 `true`：每次打开游戏金币都是 **99999（上限）**，所有已开放的关卡直接解锁（含 Boss Rush 星光节点、婚纱皮肤可直接买），标题页底部会显示"开发者模式"。
> ⚠ 现在 `config.js` 里 `devMode` 是 **`true`**（你测试时打开的），交付前改回 `false`。
它用的是独立存档（第一次开启时会复制一份正式存档的进度），关掉后自动回到正式存档，互不影响。**交付前务必改回 `false`。**

## 二、操作

| 动作 | 键盘 | 手机 / 鼠标 |
|---|---|---|
| 变道 | ← → / A D | 左右滑（按住拖动也行） |
| 跳跃 | ↑ / W / 空格 | 上滑 |
| 滑铲（空中 = 急降） | ↓ / S | 下滑 |
| 反击 | J | 点击（完美反击拍击 / 投掷型蓄力条 / 备用弹药） |
| 技能「回忆闪光」 | L | 双击屏幕（技能条满时） |
| 暂停 | Esc / P | 右上角 Ⅱ 按钮 |

**完美闪避**：障碍 / 弹幕即将撞上的 0.15 秒内做出正确闪避 → 0.3 秒子弹时间 + "叮" + 技能条 +25%（连击每级再 +5%）。

**技能「回忆闪光」**：技能条满（完美闪避 4 次 / 金币连击补充）后 **双击屏幕 / L** 释放：爱心冲击波清掉全场弹幕（每颗变成金币）+ 1.5 秒无敌；在 Boss 硬直窗口内释放，还会让这一次反击的判定更宽（投掷红区 +50% / 拍击金圈 +0.1s）。

**七个 Boss 的还击方式**（都只在 Boss 晕乎乎的硬直窗口里，砸中 3 次通关）：
- 第 1 关 喵喵 · 完美反击：她丢巨型礼盒，**等礼盒套上金圈的瞬间按 J / 点屏幕** → 一拍子把它拍回去砸她的脸（拍早了有 0.3s 冷却，被砸中只"砸懵"不扣心）。
- 第 2 关 金刚 · 踩跳：它滚来金色滚桶，**跳上桶顶** → 被弹起来，金刚冲过来被一脚踩中。
- 第 3 关 波哥 · 投掷：他掉下菠萝油，**捡起来后指针摆进红区时按 J / 点屏幕** → 扔回去；跑酷段捡的「回忆道具」是备用弹药（硬直时直接按 J）。
- 第 4 关 木木 · 冲刺：它转晕了跪在某条道上（地面绿箭头），**先站到那条道，再连按两次同一方向键（或按 J / 点屏幕）** → 冲刺撞上去。
- 第 5 关 章章 · 完美反击（选落点）：金光巨章鱼烧同样金圈时刻按 J 拍回去，然后慢动作 **选落点：章章在哪条道就按 ← / ↑ / →**（落点有金圈），选错会砸偏。
- 第 6 关 蟹老板 · 踩跳（跳板）：壳张开时会弹出一块金色跳板滑到你脚下，**站着别动等它到脚下（或跳上去）** → 弹起来踩它壳里的弱点。
- 第 7 关 吞吞 · 混合：每次硬直随机换一种（完美反击 / 踩跳 / 投掷 / 冲刺），屏幕上会提示这次是哪种。

## 七、开发决策记录（策划书未覆盖或有冲突的地方）

1. **双击运行 vs ES 模块**：Chrome/Edge 禁止 `file://` 加载模块，二者无法同时满足 → 提供 `启动游戏.bat`（Windows 自带 PowerShell，零安装）+ Firefox 可直接双击 + 页面内中文指引。
2. **渲染方案**：世界画在 170~200 × 300~420 的低分辨率缓冲上，整数倍放大（`image-rendering: pixelated`）；HUD 中文文字在主画布按屏幕分辨率绘制（不糊）；菜单用 DOM。
3. **伪 3D**：商场走廊用逐像素透视（地面 / 天花板 Mode-7 + 墙面按列求交），物体为透视缩放的像素精灵；背景是动态的，其贴图（墙面 10 级雾化版本）、全部精灵、LOVE FEVER 暗角都预先缓存在离屏 Canvas。
4. **跑段长度**：附录"260-320m"与 4.1 节"约 2 分钟 + 速度 8→14m/s"矛盾，以 4.1 为准（约 120 秒，折合约 1300m）。
5. **跳跃**：滞空固定 0.6s（附录），顶点取 1.8m；主角碰撞半深 0.3m。"跨 1.5 道宽"理解为空中可变道。
6. **购物车可落脚**：跳早了落在购物车顶上不算受击，跑出车尾掉下时有郊狼时间（让"跳过低障碍"对休闲玩家更宽容，也给郊狼时间一个实际用武之地）。
7. **侧面擦碰**：变道时从侧面蹭到障碍 → 弹回原车道 + 短暂硬直，不扣心；只有正面撞上才算受击。
8. **完美闪避判定**：按"意图"判定——动作前的状态会被撞、动作后的目标状态能躲开，且距撞上 ≤0.15s → 判定成功（即使身体还没完全移开）。
9. **子弹时间**：0.3s 真实时间内世界以 0.25 倍速运行，最后 0.08s 平滑恢复。
10. **扶梯**：上扶梯 = 速度 ×1.2 + 镜头抬高；"下扶梯反向" 理解为速度 ×0.8 + 镜头降低；扶梯区内障碍间隔按加速后速度换算，不会变挤。
11. **礼盒雨**：落地前 1.15s 锁定玩家当前车道（礼盒从高空出现），红圈预警 0.6s（读难度表）。
12. **Boss 结构**：每阶段 = 3 波 × 6s → 硬直窗口（6s）→ 还击；窗口内没打中 → Boss 缓过来，本阶段从第 2 波重来。
13. **反弹礼盒（已改为完美反击）**：硬直窗口内会反复丢；被它砸中只会"砸懵"不扣心（硬直窗口是奖励时间，不应惩罚）；礼盒上的收缩圈变金色 = 现在按 J / 点屏幕就能拍回去（躲开不再触发反弹，只是错过机会）。
14. **阶段递进**：弹幕速度 ×(1+0.22×阶段)、密度 ×(1+0.28×阶段)（线性叠加）；任何发射间隔不低于 1.0s 公平底线。
15. **Boss 重开**：恢复进入 Boss 战时的爱心 / 护盾 / 能量；金币永不回滚（失败那几次赚的也算）；重开时登场演出缩短为 1.6s（仍有 LOVE FEVER）。
16. **LOVE FEVER**：Boss 战全程开启；男友酱的换人 CD 在 FEVER 期间减半，进入 Boss 战时剩余 CD 也立即减半。
17. **爱心拾取**：满血时转 1 层临时护盾（不叠加）；护盾道具最多叠 2 层。
18. **Boss 掉金币**：每次反击命中 +5、击败爆 30 枚（给演出一点"爆金币"的爽感，数值在 `data/economy.js`）。
19. **经济**：首通 200 / 重复通关 120 / 新星每颗 50（只发一次）/ Boss 无伤 +80；本局金币无论成败全额入账。
20. **难度**：关卡准备页选择，记住上次的选择（存档 `settings.difficulty`），默认"热恋"。
21. **第 N 天**：默认在一起当天算第 0 天，满一年那天显示"第 365 天"（与副标题呼应），可在 config 切换。
22. **地图悬念**：未开放的 6 张地图显示为"？？？"，不剧透"每关都是你们去过的地方"。
23. **热身教学**：教学行铺满三道（或只留一条生路），保证玩家一定会做一次对应动作；每种障碍第一次出现弹提示。
24. **技能条「回忆闪光」**（原"还击能量"改造）：完美闪避 +25%（连击每级 +5%，封顶 +20%）；金币连击（间隔 ≤0.9s）达到 20 后每枚 +1%。满槽后双击屏幕 / L 释放：清全场弹幕（每颗变 1 金币）+ 1.5s 无敌 + 0.3s 子弹时间；硬直窗口内释放再让本次反击判定放宽（红区 +50% / 金圈 +0.1s）。原"能量满 = 硬直 +3s"效果已移除（数值并入技能）。
25. **公平性**：单帧时间上限 50ms，卡顿时宁可放慢也不让障碍"瞬移"穿过主角。
26. **Boss 弹幕运动**：在"主角空间"里飞行，与地面滚动速度无关，保证不同速度下可读性一致。
27. **矮屏适配**：Boss 悬停高度自动压低，避免挡住顶部 HUD。
28. **音频版权**：音效全部 Web Audio 实时合成；BGM 是本项目原创旋律的程序化 chiptune（`data/music.js`），没有使用任何外部音频文件，可自由使用（等同 CC0）。

**M2 新增决策**

29. **商店价格**（试玩后上调：能力 +50%、道具 +100%、男友酱 +100%）：买第 n 级 = 基础价 × n（金币嗅觉 450 / 900 / 1350 …）；一次性项目（甜心 / 弹跳鞋 / 复活机会）只有 1 级；男友酱 2400。
30. **甜心**：生命上限 +1（1 心制下 = 2 心；甜蜜模式 = 4 心）。
31. **复活**：复活机会（加点）+ 复活币（道具）可叠加；倒下后弹窗问要不要复活，原地满血复活 + 清掉 28m 内的障碍 + 2.2s 无敌；在 Boss 战里复活不消耗重开次数。
32. **Boss 护罩**：只在 Boss 战生效，挡 1 次；Boss 战重开时不会再次补上（它是消耗品）。
33. **男友酱**：开局 CD 就绪；换人后由男友酱接着跑，下次换人再换回女友酱；被换人挡下的伤害不算"受击"（不影响无受击星），但算一次"失误"（影响挑战型照片）。
34. **三星**：累计取最好（分两局拿也算）；"无受击" = 本局没有掉过心（护盾 / 换人挡下的不算）；第 3 星在通关过的前提下集齐 3 片即点亮。M1 旧存档已通关的关卡自动补上「通关」星（不补发金币）。
35. **照片碎片藏法**：
    - 岔路型：第 1 波过半时，一个堵 2 道的全高障碍正后方、被挡住的那条道上（绕开后马上切回去拿，有一小串金币指路）
    - 技巧型：第 2 波开始后，3 秒内连续 2 次完美闪避 → 前方高处出现（要跳起来拿）
    - 挑战型：第 3 波零失误（受击 / 侧面擦碰 / 护盾被打破 / 换人 / 踩便便都算失误）→ 冲刺段开头出现在路面上
    - 捡到的碎片无论本局成败都存档；已收集的不再出现
36. **中途重开 / 退出**：暂停菜单里重开或返回选关，本局金币和已捡的照片也会入账（金币永不损失）。
37. **打滑便便**：不扣心；踩到后 0.8s 内左右方向颠倒（确定性，不随机乱走），头顶冒星星提示。
38. **组合（双连）**：组内两行恰好相隔难度表的"最小间隔"，组与组之间 ×1.25 更宽松，形成"紧-松"节奏。
39. **报刊亭 S 型**：两行各堵 2 道、缺口一左一右，必须连续变 2 道；中间有一串斜金币指路。
40. **港铁闸机**：左右两道同时堵住只留中间（"三道并一道"）。
41. **人力车**：进入前方 16m 才起步往前走（3m/s），生成器按"推迟后的到达位置"摆金币和爱心，不会和后面的障碍挤在一起。
42. **企鹅纵队**：归为低障碍（可以跳过），到达前 1.2~3s 从路边出发横穿马路。
43. **每关一颗爱心**：放在该关可站立障碍的顶上（商场购物车队 / 动物推车 / 人力车），得先跳上去。
44. **金刚**：地面 Boss，在前方 22m 边跑边往后扔；香蕉皮地毯 = 两条道亮红、第三条道前面放跳板（踩上去强制高弹 1.25s 飞过地毯）。踩跳还击：金色滚桶撞上只会"砸懵"不扣心。
45. **波哥蓄力条**：指针来回摆动（周期 1.3s），红区占 20%；4 秒不按自动扔；扔偏会飞到路边，波哥稍后再掉一个；菠萝油没捡到会再掉。回忆道具 = 备用弹药，硬直时按 J 直接开始蓄力。
46. **香港夜雨**：纯视觉（压暗 + 斜雨丝 + 霓虹闪烁），不影响任何判定。
47. **关卡解锁**：通关上一关即解锁下一关；点开某关的准备页时，背景会切换成这张地图。
48. **Boss 弹幕错开**：不同种类的攻击"打到主角的时刻"至少错开 0.6s（`BOSS_RULES.mixedGap`），冲突时后发的那个自动推迟并先占住时间段（不会一直被挤掉）——修复波哥"奶茶堵两道 + 菠萝油砸在空道"的无解情况。喵喵的 `stagger: false` 已移除：需要重叠的攻击一律走显式组合技（见决策 70）。
49. **难度曲线**（试玩后调整，偏离 4.4 表）：第 1~3 关不变；第 4~7 关速度上限 18→24、最小间隔 1.45→1.0s、同屏上限 3→6、Boss 弹幕 ×1.25→×1.7、硬直窗口 5.4→3.8s。疯狂模式第 4 关起每关再叠加：间隔 -0.1s、预警 -0.02s、弹幕 +8%。公平底线（间隔 ≥ 1.0s、预警 ≥ 0.35s）不变。
50. **存档与端口**：浏览器存档跟"网址 + 端口"绑定。`启动游戏.bat` 发现游戏服务器已经在 8765 运行时直接复用（不再换到 8766、8767…导致"存档消失"）；局内直接关掉页面时，本局金币和照片也会入账；开发者模式第一次开启时从正式存档复制进度。

**M3 新增决策**

51. **弹床（游乐园）**：做成一段"弹床区"（地面黄蓝条纹），区内只要落地就被自动弹起 0.9s；空中照常变道 / 急降。爱心放在弹床弧线的顶点（3.4m 高），不弹起来拿不到。
52. **冲刺型还击（木木）**：转晕的木木跪在绿箭头那条道的近处（8m）。操作 = 站到那条道后**连按两次同一方向键**（0.3s 内），或直接按 J / 点屏幕。为了不和普通变道冲突：已经对准时，第一下方向键会被"扣住"0.3s，等不到第二下才当作普通变道执行。
53. **选落点（章章）**：完美闪避弹回巨章鱼烧后进入 2.2s 慢动作，章章随机站到一条道（脚下金圈）；按 ← / ↑（或 J）/ → 选落点，时间到按主角当前所在道自动选；选错 = 砸偏，章章缓过来继续打。
54. **跳板型踩跳（蟹老板）**：硬直时蟹老板吐出金色跳板，沿主角所在道滑过来；踩上（站着不动也会踩上）→ 弹起 1.1s → 踩中壳里的弱点。
55. **混合终局（吞吞）**：4 种还击（反弹 / 踩跳 / 投掷 / 冲刺）洗牌后依次出现（3 次硬直 → 必有 3 种不同的），每次登场有提示文字。
