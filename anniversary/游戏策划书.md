# 《奔向你 · 我们的365天》游戏策划书

> 一周年纪念礼物 · 网页版关卡制跑酷游戏
> 版本 v1.5 · 2026-10（v1.5：Boss 战重开规则——失败金币不损失、从 Boss 战开头重开，每关限 2 次，3 次挑战失败即本关失败）

---

## 1. 项目概述

| 项目 | 内容 |
|---|---|
| 游戏名 | 《奔向你》（副标题：我们的365天） |
| 类型 | 关卡制 3D 视角跑酷（类地铁跑酷）+ Boss 战 + 局外养成 |
| 平台 | 网页（桌面浏览器 + 手机浏览器），可做成 PWA 添加到主屏幕 |
| 技术 | 原生 Canvas 2D + 模块化 JS，零依赖，localStorage 存档，GitHub Pages 免费部署 |
| 美术 | 像素风（16×16 放大渲染），每张地图独立配色 |
| 目标玩家 | 女朋友（休闲玩家），难度以"甜蜜模式"为基准设计 |
| 单局时长 | 每关约 3 分钟（跑段 2 分钟 + Boss 战 1 分钟） |
| 核心概念 | 跑过这一年去过的每一个地方，打败每个场景里的小麻烦，最终跑回家——打开回忆放映厅 |

**一句话概念**：她以为是普通的跑酷游戏，通关后才发现，每一关都是你们这一年走过的地方，集齐照片碎片后解锁一周年隐藏结局。

## 2. 核心循环

```
选关 → 装备出战道具 → 跑酷段(收集金币/道具/照片碎片) → Boss战(躲避+还击)
  → 结算(星级/金币/碎片) → 商店消费(永久强化/道具/皮肤) → 挑战下一关/重刷
```

- **进度推进**：击败 Boss 即通关并解锁下一张地图，共 7 关。
- **重复游玩动力**：刷金币买强化、三星评价（无伤/全收集）、隐藏照片碎片、通关后的无尽模式。

## 3. 操作设计

### 3.1 桌面（键盘）

| 按键 | 动作 |
|---|---|
| ← → / A D | 左右变道 |
| ↑ / W / 空格 | 跳跃 |
| ↓ / S | 滑铲（可打断跳跃快速下落） |
| J / 鼠标点击 | 反击投掷（Boss 战硬直窗口时） |
| Esc | 暂停 |

### 3.2 手机（手势）

| 手势 | 动作 |
|---|---|
| 左右滑动 | 变道 |
| 上滑 | 跳跃 |
| 下滑 | 滑铲 |
| 点击 | 反击投掷 |

### 3.3 动作规则

- 三车道，跳跃可越过低障碍，滑铲钻过高障碍和横杆，变道躲全高障碍。
- 空中允许变道（手感宽容，照顾休闲玩家）。
- 跳跃高度可二段跳：**默认无二段跳**，商店购买"弹跳鞋"强化后解锁（给局外养成一个手感上的奖励）。
- **完美闪避**：在障碍即将命中的 0.15 秒内完成闪避动作 → 触发 0.3 秒子弹时间 + "叮"音效 + 反击能量 +10%。这是 Boss 战"反弹类还击"的触发条件，也是高手向的爽点。

### 3.4 生命模型（v1.4 · 1 心制）

- 默认只有 **1 颗爱心**：除护盾、出战道具、伙伴"守护换人"挡下的情况外，任何一次受击都直接本关失败——生存靠操作和羁绊，不靠血条（购买"甜心"加点后上限提升为 2）。
- 受击结算顺序：无敌帧 → 护盾 → 伙伴"守护换人"挡下 → 失败，详见 8.2D。
- 跑段中偶有心形拾取物（约每关 1 个）：回 1 心；生命已满时转化为 1 层本关临时护盾（不叠加）。
- **体贴设计**：Boss 战失败后从 Boss 战开头重开（不重跑跑酷段），金币不损失；每关有 **2 次重开机会**，第 3 次挑战 Boss 失败即本关失败（已收集金币仍全额入账，只是没有通关奖励与星级）。

## 4. 跑酷段玩法

### 4.1 节奏结构（每关通用）

| 阶段 | 时长 | 内容 |
|---|---|---|
| 热身段 | ~15s | 低速，仅金币和简单摆放障碍，教学本关新机制 |
| 波次段 ×3 | ~90s | 障碍密度逐波上升，波与波之间插入纯收集段（磁铁/金币弧线）喘息 |
| 冲刺段 | ~15s | 速度拉满 + 金币雨，情绪推到最高点 |
| Boss 登场 | 3s | 镜头演出，速度锁定，进入 Boss 战 |

### 4.2 速度曲线

- 基础速度 8 m/s，随关卡进度线性升到该关上限（第 1 关 14 m/s → 第 7 关 20 m/s）。
- Boss 战锁定 12 m/s（保证弹幕可读）。

### 4.3 障碍类型分类（Taxonomy）

所有地图的障碍都由以下 6 类组合而成，每张地图的差异化体现在：专属外观 + 专属行为参数 + 1 个专属机制。

| 类别 | 行为 | 应对 |
|---|---|---|
| 低障碍 | 静止，齐膝高 | 跳 / 变道 |
| 高障碍 | 静止，悬空横杆 | 滑铲 / 变道 |
| 全高障碍 | 静止，堵满整道 | 变道 |
| 移动障碍 | 横向巡逻、往复、跟随 | 预判变道 |
| 弹道障碍 | 抛物线/直线飞来，落点提前红圈提示 | 移动出落点 / 跳过地面波 |
| 场景机制 | 每图专属：扶梯、弹床、油渍、窄道等 | 改变操作节奏 |

**通用反馈规则**：一切弹道物落地前在地面显示红色警示圈，基础预警 0.6s，随关卡难度递进收紧到最短 0.35s（见 4.4）——0.35s 是休闲友好底线，任何时候不突破。

### 4.4 难度递进曲线（跨关卡）

普通关卡之间的难度必须逐关可感知地上升，但只从三个**可量化维度**增长，不从"耍赖"维度增长：

1. **反应时间**：两次必需操作之间的最小间隔逐关缩短（核心压力来源）；
2. **信息密度**：同屏障碍数量、每波障碍种类数逐关增加；
3. **执行复杂度**：障碍从单个 → 双连 → 三连 → 混编组合。

公平性底线只小幅收紧（预警时间），而技能表达空间（完美闪避窗口）全程恒定——"更快、更密、更连贯"，绝不"更赖"。

| 参数 | 关1 | 关2 | 关3 | 关4 | 关5 | 关6 | 关7 |
|---|---|---|---|---|---|---|---|
| 速度上限 (m/s) | 14 | 15 | 16 | 17 | 18 | 19 | 20 |
| 障碍最小间隔（反应时间） | 2.2s | 2.0s | 1.8s | 1.6s | 1.5s | 1.4s | 1.2s |
| 同屏障碍上限 | 2 | 2 | 3 | 3 | 4 | 4 | 5 |
| 组合障碍长度 | 单个 | 双连 | 双连 | 三连 | 三连 | 四连 | 混编 |
| 每波障碍种类数 | 1-2 | 2 | 2-3 | 3 | 3 | 3-4 | 全部 |
| 弹道预警时间 | 0.6s | 0.55s | 0.5s | 0.45s | 0.4s | 0.38s | 0.35s |
| Boss 弹幕速度系数 | 1.00 | 1.05 | 1.10 | 1.15 | 1.20 | 1.25 | 1.30 |
| Boss 硬直窗口 | 6.0s | 6.0s | 6.0s | 5.8s | 5.6s | 5.4s | 5.2s |

**递进设计守则**

- 关 7 的 1.2s 最小间隔对休闲玩家是"手忙脚乱但能过"的甜点区；低于 1.0s 判定为不公平，全游戏（含无尽模式）不出现。
- 新机制永远在本关热身段低速教学；每关前 20% 是上一关内容的复习+热身，之后才进入本关压力区间。
- 速度上限每关只 +1 m/s（体感温和），压力增长主要交给间隔与密度——玩家会觉得"这关更挤了"而不是"这关更快了"，挫败感更低。
- 完美闪避窗口恒定 0.15s：难度上升来自局面更复杂，而不是判定更苛刻。
- 甜蜜模式全局修正：间隔 +0.4s、预警 +0.15s、Boss 弹幕速度 -15%（关 7 甜蜜 ≈ 标准难度的关 5 压力，保证她能通关）。

### 5.1 第1关 · 商场（教学关）

**专属障碍**

| 障碍 | 类别 | 行为 |
|---|---|---|
| 购物车队 | 低障碍 | 连排购物车，需跳 |
| 促销横幅 | 高障碍 | 悬空横幅杆，滑铲 |
| 摆件花坛 | 全高障碍 | 变道 |
| 观光人群 | 移动障碍 | 慢速横移的一家三口 |
| 礼盒雨 | 弹道障碍 | 天上掉礼盒，红圈提示 |

**专属机制 · 扶梯**：上扶梯时镜头抬高、速度 +20%，下扶梯反向——第一次用"速度呼吸感"制造新鲜感。

**Boss · 促销气球吉祥物「喵喵」**：一只巨大的充气吉祥物，把促销台当武器。
- 阶段1：丢**盲盒**（落地弹开成扇形彩纸，跳过）
- 阶段2：横扫**购物车**（横贯两道，需提前站好剩余道）
- 阶段3：**优惠券弹幕**（满屏纸片，节奏跳/铲）
- **还击（反弹型）**：阶段3结束后喵喵会丢出一个**巨型礼盒**，此时引导教学："在礼盒即将命中时闪避（完美闪避）即可把它打回去！"命中喵喵脸 3 次（3 HP）过关。

### 5.2 第2关 · 动物园

**专属障碍**

| 障碍 | 类别 | 行为 |
|---|---|---|
| 动物推车 | 低障碍 | 双轮小车，跳 |
| 横杆告示 | 高障碍 | "小心动物"指示牌，滑铲 |
| 孔雀车 | 全高障碍 | 变道 |
| 企鹅纵队 | 移动障碍 | 3 只一排横穿马路 |
| 猴子香蕉 | 弹道障碍 | 路边猴子抛香蕉，抛物线 |

**专属机制 · 打滑便便**：踩到地面动物便便 → 0.8s 内变道方向随机颠倒（有卡通打滑音效，扣心但不至于死，属"喜剧障碍"）。

**Boss · 越狱大猩猩「金刚」**：金刚在前面跑，边跑边往后扔东西。
- 阶段1：**滚桶**（ barrels 占一道滚来，跳过；致敬马里奥）
- 阶段2：**香蕉皮地毯**（地面成片，必须踩跳板起跳越过）
- 阶段3：**桶+香蕉混合波**，速度加快
- **还击（踩跳型）**：阶段3后金刚累了停下喘气，它扔的滚桶变为"可踩"状态（发金光）——跳上桶弹起、落到金刚头上踩一下。踩中 3 次过关。

### 5.3 第3关 · 香港街头

**专属障碍**

| 障碍 | 类别 | 行为 |
|---|---|---|
| 双层巴士站牌 | 全高障碍 | 变道 |
| 报刊亭 | 全高障碍 | 连续两个，S 型变道 |
| 人力车 | 低障碍 | 慢速前移，追尾感 |
| 招牌坠落 | 弹道障碍 | 霓虹招牌从楼上掉落，红圈提示 |
| 港铁闸机 | 场景机制 | 窄道：三道瞬间并为一道，必须居中 |

**专属机制 · 霓虹夜雨**：中段开始下雨，地面反光、霓虹灯牌闪烁遮挡部分视野（视觉压力来自美术而非判定，判定不变——表面难实际公平）。

**Boss · 茶餐厅老板「波哥」**：端着托盘的胖老板，把招牌菜当弹药。
- 阶段1：**丝袜奶茶波**（直线弹，三道各一发，留一个空档）
- 阶段2：**菠萝油三连**（抛物线三个落点连环）
- 阶段3：**镬铲地波**（地面冲击波，必须跳）
- **还击（投掷型）**：波哥疲劳时会掉落**菠萝油**在地上（发光），拾取后底部出现"蓄力条"——在指针摆到红区时按反击键，把菠萝油扔回去砸波哥。投中 3 次过关。蓄力条玩法给 Boss 战加入"准头"乐趣。

### 5.4 第4关 · 游乐园

**专属障碍**

| 障碍 | 类别 | 行为 |
|---|---|---|
| 气球束 | 低障碍 | 跳 |
| 旋转杯 | 移动障碍 | 原地旋转的茶杯车，占道往复 |
| 摩天轮支架 | 高+全高组合 | 滑铲后立刻变道 |
| 小丑彩带 | 弹道障碍 | 彩带卷成直线弹 |
| 弹床区 | 场景机制 | 踩上强制高弹跳，空中铺金币弧线 |

**专属机制 · 弹床连跳**：连续弹床区，跳跃节奏从"地面起跳"变为"空中接弹"，节奏游戏感最强的一关。

**Boss · 失控旋转木马「木木」**：一只脱轨旋转的木马，绕圈甩出攻击。
- 阶段1：**木马环绕**（两匹木马绕它旋转，周期性扫过三道，找间隙）
- 阶段2：**彩环弹幕**（套圈抛物线散布）
- 阶段3：**转盘冲刺**（横扫全场，必须踩它吐出的弹床跳过）
- **还击（冲刺型）**：木木转晕后"眼冒金星"跪地，地面出现冲刺绿箭头——对准它按两次变道键冲刺撞击。撞 3 次过关。冲刺手感酣畅，是节奏上的情绪峰值。

### 5.5 第5关 · 夜市

**专属障碍**

| 障碍 | 类别 | 行为 |
|---|---|---|
| 小吃摊车 | 全高障碍 | 连续摊车，S 型 |
| 塑料凳阵 | 低障碍 | 密集连排，跳跳跳 |
| 灯笼串 | 高障碍 | 滑铲 |
| 烤串竹签雨 | 弹道障碍 | 斜落竹签，落点密集 |
| 人潮波浪 | 移动障碍 | 人群成波次横穿，像浪一样一波接一波 |

**专属机制 · 摊位喇叭**：路边喇叭会"叫卖"（音效+头顶气泡），被气泡吸引的 NPC 会突然横穿——用声音做假动作，考验耳朵。

**Boss · 章鱼烧老板「章章」**：八手同时翻章鱼烧的老板。
- 阶段1：**章鱼烧弹珠**（多颗弹地球，落地反弹，走位躲）
- 阶段2：**木鱼敲击波**（节奏型地面波，跟着节拍跳）
- 阶段3：**全弹发射·章鱼烧暴雨**
- **还击（反弹型·进阶）**：阶段3最后必出一颗**金光巨章鱼烧**，完美闪避反弹，且反弹后需再按一次方向键选择落点砸章章。反弹 3 次过关。

### 5.6 第6关 · 海边

**专属障碍**

| 障碍 | 类别 | 行为 |
|---|---|---|
| 沙滩椅 | 低障碍 | 跳 |
| 冲浪板架 | 高障碍 | 滑铲 |
| 礁石群 | 全高障碍 | 变道 |
| 潮汐 | 场景机制 | 海浪周期性漫上两侧道，必须站中间道（屏幕边缘泛蓝提示） |
| 水母漂浮 | 弹道障碍 | 慢速悬浮物，空间压缩 |

**专属机制 · 潮汐涨落**：本关的"呼吸感"来自潮水：潮涨时可用道从 3 变 1，潮退时全开且滩涂上铺满金币——风险与奖励同源。

**Boss · 巨型螃蟹「蟹老板」**：横行霸道的大螃蟹。
- 阶段1：**泡泡弹幕**（漂浮泡泡，从两侧向中间合拢）
- 阶段2：**巨钳横扫**（左钳右钳交替扫全场，必须跳钳缝）
- 阶段3：**吐沙暴**（视野风沙 + 混合弹幕，本关视觉压力峰值）
- **还击（踩跳型·进阶）**：蟹老板疲劳时壳会张开露出发光弱点，用跳板跃起**踩壳内弱点**。踩 3 次过关。

### 5.7 第7关 · 家（最终关）

**关卡设计**：前半段是"回家路"——雨夜街道、路灯、便利店，所有前 6 关障碍以 weakened 形式混编回归（Boss Rush 前的回忆杀）。跑到家门口，门被撞开——最终 Boss 登场。

**专属机制 · 回忆走廊**：中段进入"相片走廊"，两侧挂满发光相框（就是照片碎片图鉴的预览），节奏放缓 10 秒——情绪铺垫。

**最终 Boss · 忘却兽「吞吞」**：一只偷吃回忆的灰色小怪兽，肚子里全是你们这一年被它吞掉的光点。
- 阶段1：复刻喵喵的盲盒扇形（慢速版）
- 阶段2：复刻金刚的滚桶 + 波哥的地面波
- 阶段3：复刻木木的环绕 + 章章的弹地球 + 蟹老板的泡泡（全混考）
- **还击（混合型·终局）**：每个阶段疲劳后，随机触发四种还击之一（反弹/踩跳/投掷/冲刺），把"这一年学会的所有本事"用一遍。
- **剧情演出**：击败后吞吞吐出所有光点，光点飞回家中——切换到隐藏结局《回忆放映厅》（见第 9 章）。

### 5.8 隐藏关卡 · Boss Rush「回忆风暴」

**开启条件**：照片碎片 21/21 全收集（即已看过《回忆放映厅》）。达成后，地图选择画面"家"的节点之后浮现第 8 个星光节点——这是给全收集完成者的终极邀请函。

**形态**：无跑段，纯连战。7 只 Boss 按首次登场顺序依次返场（吞吞压轴），两场之间穿插 **5 秒星光补给段**（地面铺爱心与拾取物，同时镜头切到下一只 Boss 登场）。总时长约 7~8 分钟，是全游戏最长的单次挑战。

**难度定位：略高于正常关卡**

| 项 | 正常关卡 | Boss Rush |
|---|---|---|
| 弹幕速度 | 1.0~1.3× | 在对应 Boss 系数上再 +10% |
| Boss 硬直窗口 | 5.2~6.0s | 固定 5.0s |
| 生命 | 每关 1 心 | 全程共享 2 心；每个补给段最多回 1 心 |
| 波次衔接 | 波次间有小喘息 | 衔接更紧（波间间隔 -0.5s） |
| 叠加压力 | 无 | 每击败 1 只，下一只弹幕密度 +5%（累计叠加） |

**专属规则**

- 中途失败：从**当前这只 Boss** 重开，不退回第一只，且**无重开次数限制**（终局挑战靠它自身的强度守门，不靠次数；每次重开金币同样不损失）。
- 单场无伤击败一只 Boss → 金光特效 + 立即回 1 心（高手续航奖励）。
- Boss Rush 不提供难度切换：甜蜜难度玩家按标准参数 -10% 参与（保留挑战尊严，也留一条活路）。

**通关奖励 · 成就感三件套**

1. **纪念动画「群星之夜」**：7 只被打服的 Boss 从各自的地图赶来，聚到星空下的家门口和主角合影；烟花在夜空中拼出 **365**，再缓缓化作 **∞**；镜头定格成一张拍立得，飞进回忆放映厅，成为**第 22 张照片**——放映厅因此多出最后一页。动画尾声滚动制作名单，出品人一栏写着你的名字。
2. **白金奖章「年度最佳搭档」**：永久陈列在标题画面存档名旁，全游戏最高荣誉；点开可查看通关用时、无伤场次等战绩记录。
3. **专属皮肤「星光礼服」**：通关免费解锁（不进商店），星空配色双人礼服，奔跑时带星尘拖尾——全游戏唯一带动态特效的皮肤，让"我打穿了 Boss Rush"在每一次开局时都被看见。

## 6. Boss 战系统（通用规则）

### 6.1 结构

```
登场演出(3s：Boss 名条 → LOVE FEVER 宣告，见 6.4) → [弹幕波A(8s) ×3 → 硬直窗口(5.2~6s) → 还击机会] × 3 阶段 → 击败演出(5s)
```

- Boss HP = 3，每次成功还击 -1。
- 每进入下一阶段，弹幕速度 +15%、密度 +20%。
- 硬直窗口内 Boss 挂"眩晕星星"，屏幕给大字提示还击方式。
- 玩家被弹幕命中：1 心制下即本关失败（出战道具 Boss护罩、护盾、守护换人可挡，结算顺序见 8.2D）——由"Boss 战重开"兜底，不打断挑战节奏。
- 失败 → "Boss战重开"：从 Boss 战开头重来（不重跑跑酷段），本局金币不损失；每关限 **2 次重开**，第 3 次挑战失败即本关失败——已收集金币全额入账，只是没有通关奖励与星级。
- 复活（"复活机会"加点或复活币）不消耗 Boss 战重开次数。

### 6.2 四种还击方式

| 方式 | 操作 | 首次出现 | 爽点 |
|---|---|---|---|
| 反弹 | 对飞行物完美闪避，自动弹回 | 第1关 | 毫厘之间的成就感 |
| 踩跳 | 跳上可踩物弹起，落Boss弱点 | 第2关 | 马里奥式的直觉 |
| 投掷 | 拾取Boss掉落物，蓄力条红区出手 | 第3关 | 准头与时机 |
| 冲刺 | 疲劳时按方向键两连冲刺撞击 | 第4关 | 酣畅的速度感 |

### 6.3 还击能量（局外联动）

- 完美闪避、连续收集金币（连击 ≥20）会积攒**还击能量**。
- 能量满 → 下一次硬直窗口时间从 6s 延长到 9s（商店"专注"强化可再加）。
- 设计目的：跑段的经营（吃金币、完美闪避）直接反哺 Boss 战，两个阶段不割裂。

### 6.4 登场演出与 LOVE FEVER

- **登场演出（3s）**：Boss 跃入画面 → 大字名条压屏（Boss 名 + 称号，如「越狱大猩猩 · 金刚」）。
- 名条约 1.5s 后，屏幕燃起粉色光效，弹出 **「LOVE FEVER!!」** 大字并伴随心跳加速音效——宣告羁绊增益生效：**Boss 战期间守护换人 CD 减半**（跑段 60s/满级 30s → Boss 战 30s/满级 15s），进入 Boss 战瞬间，当前剩余 CD 也一并减半。
- LOVE FEVER 视觉持续整个 Boss 战：屏幕边缘粉色流光、爱心粒子飘落、换人 CD 环形 UI 变为粉色；此期间换人演出额外弹 "LOVE!" 字样。
- 叙事含义：Boss 面前两个人的守护欲燃烧到极致，换手守护更频繁——Boss 战越危险，羁绊越强。

**D. 伙伴能力 · 男友酱「守护换人」**

男友酱不是皮肤，而是可购买的生存型伙伴能力——买的是"他会替你挡伤害"这件事本身。

| 项目 | 内容 |
|---|---|
| 解锁价格 | 1200 金币（一次性） |
| 效果 | 女友酱即将受击且换人 CD 就绪时：本次伤害无效，男友酱自动换入场守护；男友在场受击时同理换回女友酱——两人轮流替对方挡伤 |
| CD | 跑段基础 60s；加点「守护羁绊」每级 -6s，满级 30s；Boss 战 LOVE FEVER 期间 CD 减半（基础 30s / 满级 15s，见 6.4） |
| 附带加成 | 男友酱在场期间，完美闪避判定窗口 +0.02s（"有他在，更稳"） |

**受击结算顺序**（全局唯一标准，代码按此实现）：
无敌帧中 → 判无效 → 有护盾 → 破盾、不扣心 → 换人 CD 就绪 → 换人挡下、不扣心 → 正常扣心。

**规则细节**

- CD 未就绪时受击正常扣心，不强制切换。
- 跑段、Boss 战、无尽模式、Boss Rush 全部生效（Boss Rush 共享 4 心，它尤其珍贵）。
- 被换人挡下的命中不算"损失爱心"，因此不破坏"无伤★"（无伤★ 判定 = 未损失爱心）。
- 换人瞬间获得 0.8s 无敌，防止换人演出中被二连击。

**切换动画「接力」**

- 节奏：受击瞬间 hit-stop 凝滞 0.1s → 一道白色闪光斜划屏幕 → 守护者从屏幕侧滑铲入场、被挡者向后轻跃离场，两人在中线"击掌接力"定格 → 爱心粒子迸开、弹出描边大字"守护！"→ 恢复奔跑，总时长 0.25s。
- 双向动作不同：女友→男友为滑铲入场，男友→女友为翻转入场，时长一致。
- UI 呈现：爱心栏旁显示当前在场角色小头像，CD 以头像环形进度冷却，转满发光表示就绪。
- 音效：短促"心跳 + 叮"二连音，被挡一方另有轻柔气声，强调"被接住了"。

## 13. 设计决策记录（v1.2 已全部定案）

| # | 事项 | 决策 | 说明 |
|---|---|---|---|
| 1 | 屏幕方向 | **竖屏优先** | 手机竖屏为主（更接近地铁跑酷的持机习惯），桌面浏览器自适应横屏布局 |
| 2 | 默认主角 | **女孩** | 她玩"自己"：女孩跑过这一年的每一个地方，最终跑回家；男友酱改为可解锁皮肤 |
| 3 | 通关回信/通知交互 | **不做** | 保持纯离线单机的完整性，情绪终点集中在回忆放映厅与群星之夜动画 |
| 4 | 男友酱定位（v1.3） | **伙伴能力，非皮肤** | 「守护换人」：受击自动换人互挡、CD 可加点缩短、专属切换动画（见 8.2D） |
| 5 | 生存体系（v1.4） | **1 心制 + 守护换人 CD 重做** | 默认 1 心，未被守护换人/护盾挡下时第二次受击即失败；换人 CD 跑段 60s/满级 30s，Boss 战 LOVE FEVER 期间减半（见 6.4、8.2D） |
| 6 | Boss 战重开规则（v1.5） | **2 次重开制** | 失败金币不损失、从 Boss 战开头重开，每关 2 次；3 次挑战失败即本关失败（金币仍全额入账，Boss Rush 不限次数） |
