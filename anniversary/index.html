你是直接双击打开的 index.html。
Chrome / Edge 出于安全策略，不允许本地文件加载 ES 模块。

解决办法（任选其一）：

  1. 双击项目里的 「启动游戏.bat」（会自动开一个本地服务器并打开浏览器）
  2. 用 Firefox 浏览器直接打开 index.html
  3. 部署到 GitHub Pages 后用网址打开（手机推荐这种）
